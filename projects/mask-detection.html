The project

A real-time system that uses an Android phone as a webcam to detect whether someone is wearing a face mask, wearing it incorrectly, or not wearing one at all. Three classes, 96.7% accuracy, fully built from scratch without pre-trained models.

Everything is manually implemented: every convolution layer, every loss calculation, every training loop. No YOLOv8, no framework hiding the hard parts.

What makes this technically challenging

Two complete systems built, deliberately chose which to use

First built a YOLO-style object detector from scratch — grid-based detection, three-component loss, NMS — and discovered that approach needs 10x more data than was available. Deliberately switched to face cascade + classifier, which with 14,535 images did generalise.

YOLO-style detection loss implemented from scratch

Objectness loss, class loss and box regression loss as separate components, including the sqrt-trick for small bounding boxes and weighted λ-terms as in the original YOLO paper. Normally hidden behind a library.

Non-Maximum Suppression written manually

IoU calculation, confidence threshold and overlap filtering fully self-written — sits behind a single function call in most frameworks.

Domain shift identified and resolved

The first dataset (Asian motorcycle helmets) reached 81% accuracy in evaluation but did not work in practice. Diagnosing the problem as domain shift rather than just 'it doesn't work'.

96.7% accuracy on 14,535 images with a network of 101,858 parameters — fully self-built, every layer, every loss, every training loop manually implemented.

What I learned

  • How convolutions, pooling and BatchNorm work together in a CNN.
  • How backpropagation, CrossEntropyLoss and Adam optimizer make the network learn.
  • What overfitting is and how to prevent it, and when to adapt architecture choices to your data.
  • Why data quality and diversity weigh heavier than model complexity.
  • How to build a complete ML pipeline: load data → train → evaluate → real-time inference.
