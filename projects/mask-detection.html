Het project

Een realtime systeem dat via een telefoon als webcam herkent of iemand een mondkapje draagt, het fout draagt, of geen mondkapje heeft. Het systeem detecteert eerst het gezicht via OpenCV en classificeert de crop vervolgens met een zelfgebouwd Convolutional Neural Network.

Belangrijk: alles is van scratch gebouwd — geen YOLOv8, geen voorgetraind model, geen framework dat de moeilijke delen verbergt. Elke laag, elke loss berekening, elke trainingsloop is handmatig geïmplementeerd.

Wat maakt dit technisch zwaar

YOLO-stijl detection loss van scratch

De meeste ML-cursussen geven je een loss function kant-en-klaar mee. Hier is die zelf geïmplementeerd met drie aparte componenten: objectness loss, class loss en box regression loss — inclusief de sqrt-trick voor kleine bounding boxes en gewogen λ-termen zoals in het originele YOLO-paper.

Grid-based objectdetectie

YOLO-annotaties omzetten naar een [8×8×6] grid tensor, inclusief cel-toewijzing en genormaliseerde offset-coördinaten. Dit is hoe YOLO intern werkt — normaal verborgen achter een library.

Non-Maximum Suppression zelfgeschreven

Het NMS-algoritme dat overlappende bounding boxes filtert op IoU zit in de meeste frameworks achter één functieaanroep. Hier volledig handmatig uitgeschreven.

Domain shift herkend en opgelost

De eerste dataset (Aziatische helmen) generaliseerde niet naar de eigen situatie. Het probleem zelf diagnosticeren — en niet alleen "het werkt niet" constateren — is een vaardigheid waar ML-engineers jaren ervaring voor nodig hebben.

🏆

96.7% accuracy op 14.535 afbeeldingen, met een netwerk dat volledig van scratch is gebouwd — elke laag, elke loss berekening, elke trainingsloop handmatig geïmplementeerd.

Uitdagingen

  • Laptop webcam werkte niet met OpenCV — opgelost via IP Webcam op Android.
  • Eerste datasets hadden domain shift — Aziatische helmen generaliseerden niet naar de eigen situatie.
  • Zelfgebouwde detector had te weinig data — opgelost door over te stappen op een betere Kaggle dataset.

Wat ik heb geleerd

  • Hoe convoluties werken — filters die over afbeeldingen schuiven en patronen leren herkennen.
  • Hoe een netwerk leert via backpropagation, loss functions en de Adam optimizer.
  • Wat overfitting is en hoe je het voorkomt met dropout, BatchNorm en data augmentatie.
  • Waarom datakwaliteit en diversiteit belangrijker zijn dan architectuur.
  • Hoe je een volledige ML pipeline bouwt: data laden → trainen → evalueren → realtime inferentie.
