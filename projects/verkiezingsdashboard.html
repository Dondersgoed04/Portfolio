Project goal

Build an interactive web application that visualises the results of the Dutch elections. Users can explore a map of the Netherlands showing vote distributions per district, browse party pages with charts, and discuss results on a built-in forum.

The election data was delivered as large XML files that the team parsed and processed together into a format suitable for the visualisations. The project used the most advanced stack we had worked with at HvA at that point: Java Spring Boot backend, Vue 3 frontend with TypeScript, and Docker for deployment.

My contribution

I built the complete forum feature from scratch as a coherent piece of architecture. Not just a single page, but a fully connected module with its own components, data layer, and routing:

  • ForumView.vue — overview page with sidebar, categories, and search
  • PostList.vue — list of posts with Post and Reply interfaces
  • PostItem.vue — individual post card with click-navigation to detail page
  • PostDetail.vue — detail page for a single post
  • ReplyItem.vue — reply component under a post
  • PostRepository & ReplyRepository — data fetching via repository pattern
  • Forum routes — nested routing added to Vue Router
  • Login and Register page styling (layout and buttons)

The forum is not a loose page — a coherent piece of architecture: its own components, repositories, routes and interfaces, from overview to detail page with replies.

Forum component structure

02

Biggest challenge

Setting up the navigation between the post list and detail page correctly in Vue Router, while simultaneously structuring the Post and Reply data so the repository pattern connects cleanly to the Java backend. Every click on a post had to load the right data via the router, call the repository, and render correctly.
