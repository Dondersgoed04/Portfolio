The project

A production-quality webshop for games, built as a team project in block 4. The webshop has product listings, detail pages, customer and journalist reviews, a wishlist, user registration with sessions, pagination and automated unit tests.

My contribution

My contribution was the complete checkout and payment flow, from UI to backend:

  • Checkout page — glassmorphism-style UI.
  • Payment screen — payment form connected to a third-party payment API.
  • Email service — sends an HTML confirmation email after purchase via the HBO-ICT cloud mail API, with product name, price and dynamic transaction ID.
  • Discount service — validates discount codes via an external API, both frontend and backend, with its own interface and controller.
  • Contact pages — layout and forms.

The email service feels like a real production system: after every purchase the user receives a personalised HTML email with name, product, price and a unique transaction ID.

Biggest challenge

The CI/CD pipeline broke because the DiscountService on the API side used Web Components (HTMLElement), which does not exist in a Node.js environment. By deliberately distinguishing between what works in a browser and what works in Node.js, I solved this by removing the web component imports from the API side.

This taught me how fragile a CI/CD pipeline can be to environment differences, and how to debug that.
